# my-workbench

개인·회사 디지털 자산 통합 관리 및 작업 운영체계 저장소.

## 목적

- 디지털 업무 자산과 흐름의 체계적 정리/통합
- 로컬, Google Drive, GitHub 역할 분리
- 장기 보존 자료와 최근 3개월 자료 분리 관리
- 문서, 프롬프트, 코드, 자동화 자산의 버전 관리

## 운영 원칙

1. 삭제보다 분류를 우선한다.
2. 최근 3개월 자료는 반드시 점검한다.
3. 장기 보존 자료는 로컬 원본 기준으로 관리한다.
4. 민감정보/인증정보는 GitHub에 반영하지 않는다.
5. 의미 설명 문서는 한글로 유지한다.
