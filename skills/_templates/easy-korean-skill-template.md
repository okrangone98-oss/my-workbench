# 쉬운 한글 스킬 템플릿

이 템플릿은 `my-workbench`에서 새 스킬을 만들 때 복사해서 사용한다.

## 1. 사용자에게 보이는 이름

예: `정책 문제 구조화`, `사업계획서 도우미`, `인스타 콘텐츠 만들기`

## 2. 한 줄 설명

이 스킬은 사용자가 붙여넣은 자료를 바탕으로 무엇을 만들어주는가?

예:

```text
공고문과 아이디어를 붙여넣으면 사업계획서 작성에 필요한 질문, 구조, 초안, 점검표를 만들어준다.
```

## 3. 첫 화면 메뉴

```text
무엇을 하시겠어요?

1. 새 자료 붙여넣기
2. 기존 자료 불러오기
3. AI에게 물어볼 질문 만들기
4. 초안 만들기
5. 점검표 만들기
6. 결과 저장하기
```

## 4. 사용자가 준비할 것

- 붙여넣을 원문:
- 참고할 파일:
- 원하는 결과물:
- 외부 AI 사용 여부:

## 5. 입력 예시

```text
자료 종류:
공고문 / 회의 메모 / 민원 내용 / 사업 아이디어 / 홍보 문구 / 기타

목표:
요약 / 질문 생성 / 초안 작성 / 대안 비교 / 리스크 검토 / 체크리스트 작성
```

## 6. AI에게 물어볼 질문 템플릿

```text
아래 자료를 바탕으로 다음을 정리해줘.

1. 핵심 문제
2. 이해관계자
3. 목표
4. 제약조건
5. 가능한 대안
6. 각 대안의 장단점
7. 놓치기 쉬운 리스크
8. 다음에 확인해야 할 질문

[자료]
여기에 사용자가 붙여넣은 내용을 넣는다.
```

## 7. 결과물 형식

```text
요약
- 

추천 다음 행동
1.
2.
3.

AI에게 물어볼 질문
-

초안
-

확인해야 할 위험
-
```

## 8. 안전 확인

실제 실행 전 다음을 확인한다.

- [ ] 민감정보가 포함되어 있지 않은가?
- [ ] 외부 AI에 보내도 되는 내용인가?
- [ ] 유료 API를 사용하지 않는가?
- [ ] 파일 이동/삭제/push 전 미리보기를 보여줬는가?

## 9. 내부 구현 메모

사용자에게는 한글 이름을 보여주고, 내부 명령은 짧은 영어로 유지한다.

예:

```text
한글 메뉴: AI에게 물어볼 질문 만들기
내부 명령: ai:question
```

## 10. 완료 기준

- 사용자가 명령어를 몰라도 첫 메뉴에서 시작할 수 있다.
- 결과물이 바로 복사해서 쓸 수 있다.
- AI에게 물어볼 질문이 자동으로 만들어진다.
- 중요한 실행은 항상 미리보기 후 진행한다.
