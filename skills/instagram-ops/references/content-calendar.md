# 30일 콘텐츠 캘린더 템플릿

## 사용법
이 파일은 모드 A (30일 콘텐츠 캘린더) 요청 시 참조한다.
플랫폼·기간·특정 테마를 받았을 때 이 구조를 기반으로 커스터마이징한다.

## 캘린더 커스터마이징 변수

요청 시 아래 변수를 확인하고 적용한다:

```
- 플랫폼: 인스타그램 / 쓰레드 / 틱톡 (기본: 인스타그램)
- 기간: 30일 / 7일 / 특정 이벤트 기간
- 집중 기둥: 4개 중 강조할 것 있는가?
- 특별 일정: 시즌 이벤트, 캠페인, 제품 출시 등
- 업로드 가능 빈도: 주 3회 / 5회 / 매일
```

## 게시물 복붙용 캡션 템플릿

### 릴스 캡션 구조
```
[후킹 첫 줄 — 15자 이내, 질문 또는 역설]

[본문 — 3~5줄, 핵심만]

[CTA 1개 — 댓글/저장/팔로우 중 하나]

#파책남 #[주제태그 10~15개]
```

### 캐러셀 캡션 구조
```
[후킹 첫 줄]
(➡️ 슬라이드 넘겨보세요)

[1~2줄 요약]

[저장 유도 CTA]

#파책남 #[주제태그]
```

### 피드 캡션 구조 (에세이형)
```
[구체적 장면 또는 명제 한 줄 도입]

[본문 3~5문단 — 파책남 글쓰기 스킬 적용]

[마무리 — 흐릿하게 또는 단호하게]

[CTA 또는 질문 — 선택]

#파책남 #[해시태그]
```
