# 커뮤니티 & 참여 시스템 템플릿

## 사용법
모드 F (커뮤니티·참여 시스템 설계) 요청 시 참조한다.
팔로워를 팬으로 전환하는 실행 가능한 템플릿 모음이다.

---

## 1. 댓글 답글 템플릿 (브랜드 톤 유지)

### 공감 댓글에 대한 답글
```
❌ 피하기: "감사합니다! 🙏🙏🙏"
✅ 파책남 방식: 
  "맞아요, 저도 처음엔 그랬어요. 근데 [구체적 경험 한 줄] — 지금은 좀 달라졌어요 ㅎㅎ"
  "ㅎㅎ 이 부분 공감해주시는 분이 계실 줄 알았어요. [관련 경험 한 줄] — [질문 하나]?"
```

### 질문 댓글에 대한 답글
```
❌ 피하기: "DM 주세요!"
✅ 파책남 방식:
  "[핵심 답 한 줄]. 더 궁금하신 게 있으면 말씀해주세요!"
  "제 경험으로는 [구체적 답]. 다른 분들 어떻게 생각하세요?"
```

### 부정적 댓글에 대한 답글
```
❌ 피하기: 무시 또는 방어적 반응
✅ 파책남 방식:
  "맞는 말씀이에요. 저도 [인정할 부분]. 다만 제 상황에선 [내 시각]. 다르게 생각하실 수 있죠 ㅎ"
```

## 2. DM 시작 템플릿

### 비슷한 계정에 먼저 DM할 때
```
안녕하세요, [상대 이름/닉네임]님!
[최근 게시물 구체적 언급 — "어제 올리신 양양 카페 영상, 거기 저도 가봤는데 그 느낌 완벽히 담으셨더라고요"].
저도 [공통점 하나 — "양양에서 살고 있어요 / 귀촌 콘텐츠 만들고 있어요"].
앞으로 자주 뵐 것 같아서 인사드렸어요 :)
```

### 협업 제안 DM (3~4번 교류 후에만)
```
[이름]님, 그동안 콘텐츠 잘 보고 있었어요.
[공통 관심사 하나]에서 접점이 있을 것 같아서요.
[구체적 협업 아이디어 한 줄 — 부담 없이].
부담 없이 생각해보시고 아니어도 괜찮아요 :)
```

### 팔로워가 DM 왔을 때 (질문·고민형)
```
오, 이런 고민 주셔서 감사해요.
저도 [비슷한 경험 한 줄].
[답 또는 내 생각 2~3줄].
도움이 됐으면 좋겠어요. 또 궁금한 거 있으면 편하게 주세요!
```

## 3. 협업·아웃리치 템플릿

### 소규모 콜라보 제안 (1만 이하 계정 간)
```
[이름]님 콘텐츠 보면서 [구체적으로 좋았던 것]이 인상적이었어요.
저는 @slowbukbunri에서 [파책남 핵심 정체성 한 줄]을 다루고 있는데요,
[공통 오디언스 있는 주제]로 같이 뭔가 만들면 재밌을 것 같아서요.
예를 들면 [구체적 아이디어 — 인터뷰 릴스 / 캐러셀 공동 제작 / 쓰레드 멘션 교환] 같은 거요.
가볍게 한번 이야기 나눠볼 수 있을까요?
```

### 브랜드 협찬 문의가 왔을 때 검토 기준
```
✅ 수락 기준:
  - 파책남 4 코어 기둥 중 하나와 연결 가능한가?
  - 파책남이 실제로 사용하거나 공감하는 제품/서비스인가?
  - 광고임을 솔직하게 밝혀도 브랜드 이미지가 유지되는가?

❌ 거절 기준:
  - 파책남 정체성과 전혀 무관한 카테고리
  - "팔로워 늘려드립니다" 유형
  - 과도한 멘션·해시태그 강요
```

## 4. 팔로워 → 팬 전환 전략

### 4단계 전환 경로

```
1단계: 발견 (Discover)
   릴스 / 해시태그 / 공유로 처음 만남
   → 목표: 프로필 방문 유도

2단계: 정착 (Settle)
   피드·캐러셀로 "이 계정 내 취향이다" 확인
   → 목표: 팔로우 버튼 클릭

3단계: 신뢰 (Trust)
   스토리 꾸준히 보고, 댓글 달고, 저장 시작
   → 목표: 스토리 단골 뷰어 + 댓글 상호작용

4단계: 팬 (Fan)
   DM 보내고, 지인에게 계정 공유하고, 전환 행동(링크 클릭 등)
   → 목표: 커뮤니티 멤버 또는 오픈채팅/뉴스레터 가입
```

### 팬덤 신호 포착 & 활용
```
신호: 동일 인물이 3회 이상 댓글
→ 액션: 그 사람 댓글에 특별히 이름 언급해서 답글

신호: 저장율이 유독 높은 게시물 (좋아요 대비 저장 20% 이상)
→ 액션: 같은 주제로 심화 캐러셀 or 릴스 제작

신호: "이거 친구한테 보냈어요" 댓글
→ 액션: "어떤 부분이 공유하고 싶었나요?" 되묻기 (다음 콘텐츠 힌트)
```

## 5. 하루 30분 참여 루틴 (상세)

### 오전 루틴 (10분) — 업로드 당일
```
[ ] 업로드 후 첫 5개 댓글에 30분 내 답글 (알고리즘 신호)
[ ] 스토리에 게시물 공유 + "새 글 올렸어요" 멘트
```

### 낮 루틴 (10분) — 매일
```
[ ] 팔로워 중 스토리 올린 사람 3~5명 반응 (하트 또는 짧은 답장)
[ ] 비슷한 주제 계정 게시물 1~2개에 진심 댓글 (단순 "좋아요!" 금지)
```

### 저녁 루틴 (10분) — 매일
```
[ ] DM 확인 및 답장
[ ] 오늘 가장 많이 반응 받은 콘텐츠 확인 → 내일 콘텐츠 힌트로 메모
[ ] 스토리 1개 업로드 (오늘 하루 한 줄 + 질문 스티커)
```

## 6. 커뮤니티 확장 옵션 (성장 단계별)

| 팔로워 단계 | 커뮤니티 방식 |
|---|---|
| ~500명 | 댓글·DM 적극 상호작용 (1:1 관계) |
| 500~2,000명 | 오픈채팅 또는 카카오채널 개설 |
| 2,000~5,000명 | 뉴스레터 (스티비·메일리) 시작 |
| 5,000명~ | 유료 커뮤니티·클래스·멘토링 고려 |
