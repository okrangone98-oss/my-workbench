# 성과 분석 & 90일 성장 계획 프레임

## 사용법
모드 B 요청 시 사용한다.
대훈님이 [내 통계 입력]을 제공하면, 아래 프레임으로 분석하고 90일 계획을 출력한다.
통계 없이 요청이 오면: 어떤 지표를 보고 있는지 먼저 물어본다.

---

대훈님이 제공해야 하는 데이터:


## 2. 분석 출력 구조

지표를 받으면 아래 순서로 분석한다:

### 2-1. 잘 되는 것 & 근본 이유

```
잘 되는 포맷: [릴스/캐러셀/피드 중 상위]
잘 되는 기둥: [4 코어 기둥 중 성과 높은 것]
잘 되는 이유 (심리 메커니즘):
  - 오디언스가 이 콘텐츠에서 얻는 것: [정보/공감/영감]
  - 저장율이 높다면: 실용 정보 밀도가 높기 때문
  - 댓글이 많다면: 의견 갈리는 주제 또는 질문형 CTA 효과
  - 공유가 많다면: "대신 말해주는" 공감 문장 존재
```

### 2-2. 성과 떨어지는 부분 & 개선 액션

```
문제 진단 → 원인 → 실행 액션 (3가지씩)
예시:
  [문제] 릴스 조회수가 팔로워의 50% 이하
  [원인] 처음 3초 후킹 부재 / 자막 없음 / 트렌딩 오디오 미사용
  [액션] 
    1. 다음 릴스부터 첫 컷에 텍스트 자막 필수
    2. 업로드 전 트렌딩 오디오 리스트 확인 (릴스 탭 > 오디오)
    3. 첫 3초 = 결론부터. "이 영상 보면 X를 알게 됩니다" 구조
```

### 2-3. 콘텐츠 공백 & 놓친 기회

4 코어 기둥별 업로드 비율을 체크한다:
```
느린 삶: __% (권장 30%)
성장 탐구: __% (권장 30%)
로컬 크리에이터: __% (권장 20%)
솔직한 고백: __% (권장 20%)
```
편중된 기둥 → 공백 기둥 콘텐츠 3개 즉시 기획 제안

### 2-4. 최적 업로드 빈도 & 리듬

팔로워 수별 권장 빈도:
```
~1,000명:   주 4~5회 (릴스 2 + 피드 2 + 스토리 매일)
1,000~5,000: 주 5~6회 (릴스 2~3 + 피드 2 + 캐러셀 1 + 스토리 매일)
5,000~:     주 6~7회 + 스토리 2~3개/일
```

## 3. 90일 성장 계획 출력 형식

```
📊 현재 상황 요약 (한 줄)

🎯 90일 목표
  - 팔로워: [현재] → [목표]
  - 참여율: [현재] → [목표]
  - 저장 수 (월평균): [현재] → [목표]
  - 프로필 방문: [현재] → [목표]

📅 단계별 실행 계획

[1~30일] 데이터 기반 재정비
  - 집중할 포맷: 
  - 줄일 포맷: 
  - 실험할 콘텐츠 3가지:
  - 주간 체크포인트: 매주 일요일 지표 기록

[31~60일] 성장 가속
  - 잘 된 포맷 업로드 +1회/주 증가
  - 콜라보 또는 리그램 2~3회
  - 릴스 집중 공략 (알고리즘 타기)
  - 스토리 인터랙션 매일 (투표·질문 스티커)

[61~90일] 전환 & 커뮤니티
  - 링크 인 바이오 최적화
  - 리드 자석 콘텐츠 1개 완성 (저장율 높은 캐러셀)
  - 충성 팔로워 → DM 커뮤니티로 전환 시도

📋 주간 루틴
  월요일: 이번 주 콘텐츠 큐 확인 및 예약
  수요일: 중간 지표 체크 (잘 되는 게시물 있으면 스토리로 재활용)
  일요일: 주간 지표 기록 + 다음 주 계획
```

## 4. 릴스 안 터지는 이유 심층 분석

지표에서 릴스 성과가 낮을 때 이 섹션을 추가 적용한다.

### 알고리즘이 릴스를 밀어주는 신호
1. **초기 30분 참여율** — 업로드 후 30분 내 좋아요·댓글·저장이 많을수록
2. **완주율** — 영상을 끝까지 본 비율. 짧을수록 유리 (15~30초 권장)
3. **공유 수** — 좋아요보다 공유가 알고리즘에 더 강한 신호
4. **저장 수** — "나중에 다시 볼게" = 알고리즘에 강력한 양질 신호

### 파책남 릴스 최적 구조
```
[0~3초]  후킹 (텍스트 자막 + 말 또는 시각 임팩트)
[4~15초] 핵심 내용 (설명 최소화, 보여주기 중심)
[16~25초] 심화 또는 반전
[26~30초] CTA ("저장해두세요" / "팔로우!" / "댓글로 알려주세요")
```

### 파책남 계정에 맞는 릴스 유형
- **현장 브이로그형**: 서핑·양양·지역 사업 현장
- **정보 압축형**: 책 요약·AI 팁 (슬라이드 컷 편집)
- **고백 토크형**: 카메라 정면 응시 + 솔직한 말
- **비포·애프터형**: 지역 프로젝트 전후 / 귀촌 전후
