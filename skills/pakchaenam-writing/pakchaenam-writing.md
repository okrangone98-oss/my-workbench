# 파책남 글쓰기 지침 (pakchaenam-writing)

오대훈(@slowbukbunri / 파책남)의 글쓰기 스킬.
블로그 에세이·쓰레드·인스타 캡션 전용. 공문서·보고서는 이 스킬 범위 밖.

## 4기둥 (항상 유지)
솔직함 + 유쾌함 + 진정성 + 위트

## 도입부 도구 (매 글마다 다르게)
- A: 구체적 장면·시간 ("라디오에서 그 뉴스를 들은 건 퇴근길 차 안이었다")
- B: 누군가에게 한 말 ("반 년째 같은 말을 하고 있다")
- C: 명제 한 줄 → 사실로 좁히기 ("경쟁자인 줄 알았는데, 투자자였다")
- D: 추상 → 구체 (에세이형)

## 글의 구조
도입부 → 첫 생각 → 뒤집기("근데 다시 보니까") → 넓히기 → 닫기

## 인간 냄새 (AI 냄새 제거 핵심)
- "오호", "잠깐", "ㅎㅎ", "깜놀" 같은 구어적 자기 노출 의도적으로 살리기
- 정보글 중간에 고백 끼워넣기: "솔직히 나도 처음 알았다"
- 자기 자신을 한 발 떨어져서 보는 메타적 시선 유지

## 마무리 두 모드
- 흐릿 (기본): "아직 모르겠다" / "그래도 괜찮은 것 같다"
- 단호 (선택): "그래도 멈출 수는 없다" — 교훈 강요 아닌 내 행동의 선언

## 절대 금지
- "~에 대해 알아보겠습니다" / "결론적으로" / "매우", "정말" 남발
- "첫째, 둘째, 셋째" 교훈 나열
- "~해야 합니다" 강요 톤
- 각성·다짐으로 끝내는 마무리
- 고정 시그니처 반복 (같은 도입 표현이 여러 글에 반복되면 AI 냄새)

## 형태별 규칙
- 블로그: 1,200~2,000자 / 소제목 금지 / 문단 나눔으로만 흐름 조절
- 쓰레드: 3~7부작 / 각 편 100~300자 / 1편은 도구C가 가장 강함
- 인스타 캡션: 200~800자 / 첫 줄이 전부 / 이모티콘 0~2개

## 고정
- 해시태그: #파책남 항상 포함
- 어체: 한 글 안에서 통일 (평어체 또는 정중체)
