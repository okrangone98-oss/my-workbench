## 2) 문서 역할

- `PRD.md`: 저장소 운영 목표, 범위, 요구사항, 성공 기준
- `정리원칙.md`: 삭제/통합/이동 판정 시 기본 원칙
- `자산분류기준.md`: 자산 분류 체계와 상태값
- `저장위치기준.md`: 로컬/Drive/GitHub 역할 분리 기준
- `운영절차.md`: 단계별 실행 순서와 산출물
- `후속구조확장.md`: 폴더 구조 확장 단계(Phase)
- `후속작업기준.md`: 실제 확장/작업 착수 게이트와 우선순위
- `자산인벤토리템플릿.md`: 전체 자산 수집/태깅 표
- `최근3개월점검표.md`: 최근 생성 자산 주간 점검표
- `삭제후보보고서템플릿.md`: 삭제 후보 검토/승인 보고서

## 3) 운영 순서(권장)

1. 기준 문서 확정 (`PRD`, `정리원칙`, `분류기준`, `저장위치기준`)
2. 자산 인벤토리 작성 및 1차 분류
3. 통합/이동/보관/삭제 후보 실행
4. 주간/월간 점검 로그 누적
5. 필요 시 구조 확장 (`prompts`, `templates`, `workflows`, `automation`, `apps`)

## 4) 문서 관리 원칙

- 설명 문서는 한글로 작성한다.
- 기준 문서 변경과 실행 결과 변경을 분리 커밋한다.
- 민감정보/인증정보는 문서에도 기록하지 않는다.
- 기준이 바뀌면 관련 문서 3종(정리원칙/분류기준/저장위치기준)을 함께 갱신한다.
