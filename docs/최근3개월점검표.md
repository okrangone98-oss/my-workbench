# 최근 3개월 점검표 템플릿

## 1. 목적

로컬(특히 `G:\`)에서 최근 3개월 내 생성된 자산을 주간 단위로 점검하고, 유지/통합/이동/보관/삭제후보를 판정한다.

## 2. 점검 메타

| 항목 | 내용 |
|---|---|
| 점검일 | YYYY-MM-DD |
| 점검자 | 이름 |
| 점검 범위 | 예: `G:\최근3개월검토`, `G:\진행중프로젝트` |
| 점검 기간 기준 | 점검일 기준 최근 90일 |
| 기준 문서 버전 | 예: PRD v1 |

## 3. 점검 질문(자산별)

- 현재 업무/프로젝트와 직접 관련이 있는가?
- 동일/유사 최신본이 이미 존재하는가?
- 상위 구조로 통합 가능한가?
- 장기 보존 가치가 있는가?
- 민감정보가 포함되어 GitHub 반영 금지 대상인가?
- 삭제 후보로 분류해도 업무 리스크가 없는가?

## 4. 점검 결과표

| ID | 자산명 | 현재경로 | 생성일 | 최근3개월 | 중복여부 | 민감정보 | 판정상태 | 후속액션 | 담당자 | 목표일 | 메모 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| R-001 | 예시_초안.md | `G:\최근3개월검토\예시_초안.md` | 2026-02-28 | Y | Y | N | MERGE | 기준본으로 통합 후 원본 링크만 유지 | odh | 2026-03-10 | 샘플 |

판정상태: `KEEP`, `MERGE`, `MOVE`, `ARCHIVE`, `DELETE_CANDIDATE`

## 5. 실행 체크

- [ ] `DELETE_CANDIDATE` 항목은 삭제후보보고서에 등록했다.
- [ ] 민감정보 포함 항목은 GitHub 제외 처리했다.
- [ ] `MOVE`/`ARCHIVE` 항목은 대상 경로를 확정했다.
- [ ] 이번 주 실행 결과를 커밋 메시지에 남겼다.
