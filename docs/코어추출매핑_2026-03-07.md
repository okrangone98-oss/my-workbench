## 4. 우선 추출 도메인

1. `task-domain`
- Task/Activity 타입, 상태 전이, 검증 규칙
2. `classification-domain`
- `KEEP/MERGE/MOVE/ARCHIVE/DELETE_CANDIDATE` 판정 규칙
3. `workflow-domain`
- 실행 요청 포맷, 액션 타입, 결과 상태 모델
4. `report-domain`
- 인벤토리/점검표/삭제후보 보고서 생성 규격

## 5. 단계별 이관 순서

1. `packages/core`에 타입/규칙 먼저 이동
2. `apps/cli`에서 core API를 우선 사용
3. 기존 `코다리부장`의 프론트/백엔드는 어댑터 계층으로 점진 치환
4. Google/Firebase/GAS 연동은 `integrations`로 격리
