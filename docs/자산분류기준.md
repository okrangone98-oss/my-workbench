# 자산분류기준

## 1. 분류 카테고리

1. 장기 보존 자료
2. 최근 3개월 자료
3. 프로젝트 연관 자료
4. 중복 자료
5. 임시 자료
6. 삭제 후보 자료

## 2. 카테고리 정의

### 장기 보존 자료

- 장기간 재참조 가능성이 높은 원본
- 사진자료, 중요 계약/증빙, 핵심 기록
- 원칙: 로컬 원본 유지 + 백업 경로 명시

### 최근 3개월 자료

- 생성일 기준 90일 이내 파일
- 원칙: 반드시 유지/통합/이동/보관/삭제 후보 중 하나로 판정

### 프로젝트 연관 자료

- 현재 PRD/운영 목표와 직접 연결되는 파일
- 원칙: 프로젝트 구조 경로로 집약

### 중복 자료

- 동일 목적/유사 내용의 다중 파일
- 원칙: 최신본 또는 기준본 1개 선정 후 나머지는 후보 처리

### 임시 자료

- 실험, 다운로드, 중간 산출물
- 원칙: 유효기간을 정하고 만료 시 후보 처리

### 삭제 후보 자료

- 대체본 존재 또는 활용 가치가 낮은 파일
- 원칙: 후보 목록 등록 후 검토/승인 뒤 삭제

## 3. 판정 우선순위

1. 민감정보 포함 여부
2. 장기 보존 필요성
3. 현재 프로젝트 연관성
4. 중복 여부
5. 대체본/백업 존재 여부
6. 삭제 리스크

## 4. 판정 상태값(권장)

- KEEP
- MERGE
- MOVE
- ARCHIVE
- DELETE_CANDIDATE

## 5. 최소 메타데이터(권장)

- 분류일
- 분류자
- 원본 경로
- 대상 경로
- 판정 사유
- 검토 필요 여부

## 6. 운영 팁

- 먼저 폴더 단위로 1차 판정 후, 파일 단위 2차 판정 수행
- 최근 3개월 자료는 주간 단위로 반복 점검
- 삭제 후보는 월 1회 일괄 검토
