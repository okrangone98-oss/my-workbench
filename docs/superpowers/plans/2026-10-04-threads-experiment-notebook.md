# 구현 계획

1. 기록 모델·저장·병합·내보내기와 AI 요청문을 독립 모듈로 구현하고 데이터 손상·중복·무료 과금 경계를 테스트한다.
2. OpenRouter 계정 연결·무료 가격 검증·응답 해석·취소·오류 처리를 구현한다. 키를 영구 저장하지 않는다.
3. 소식 저장함, 내 관심, 출처 확인, AI 추천, 실험 기록, 학습 안내를 React 컴포넌트로 만든다. 기존 화면과 탭으로 연결한다.
4. PDF/TXT/MD 읽기와 JSON/Markdown 백업을 연결하고 반응형 화면·핵심 사용자 흐름을 브라우저로 검증한다.
5. GitHub Pages 자동 배포와 하위 경로 빌드를 설정하고 테스트·전체 빌드·린트 결과를 기록한다.
6. 작업 브랜치를 GitHub에 반영하고 PR을 통해 병합한다. 배포 결과를 확인하고 로그인 필요 등 남은 제한을 보고한다.
