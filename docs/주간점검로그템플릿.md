# 주간 점검 로그 템플릿

## 1. 목적

매주 `G:\` 로컬 자산 정리 진행상황과 판정 결과를 기록해 누락 없이 추적한다.

## 2. 점검 메타

| 항목 | 내용 |
|---|---|
| 점검 주차 | YYYY-Www |
| 점검일 | YYYY-MM-DD |
| 점검자 | 이름 |
| 점검 범위 | 예: `G:\최근3개월검토`, `G:\진행중프로젝트`, `G:\장기보관자료` |
| 기준 문서 | 예: `docs/PRD.md`, `docs/정리원칙.md` |

## 6. 다음 주 액션

1. 점검 범위를 1개 폴더 단위로 좁혀 계속 진행한다.
2. 삭제 후보는 반드시 보고서에 누적한다.
3. 구조 변경이 발생하면 커밋 메시지에 영향 범위를 남긴다.
