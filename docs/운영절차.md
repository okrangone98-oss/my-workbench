# 운영절차

## 1단계. 기준 문서 수립

- PRD 확인
- 정리원칙/분류기준/저장위치기준 확정

산출물:
- docs/PRD.md
- docs/정리원칙.md
- docs/자산분류기준.md
- docs/저장위치기준.md

## 2단계. 자산 현황 파악

- 로컬, Drive, 기존 레포의 자산 목록 수집
- 최근 3개월 자료 별도 태깅

산출물:
- 자산 인벤토리 목록

## 3단계. 1차 분류

- 장기 보존 / 최근 3개월 / 프로젝트 연관 / 중복 / 임시 / 삭제 후보 분류

산출물:
- 분류 결과표

## 4단계. 통합 계획 수립

- 중복 제거 계획
- 프로젝트 단위 통합 경로 확정
- 저장 위치 재배치 계획 수립

산출물:
- 통합 실행 계획서

## 5단계. 통합 실행

- 파일 이동/통합
- 문서/코드/프롬프트/자동화 경로 정리
- 삭제 후보 목록 갱신

산출물:
- 정리된 폴더 구조
- 삭제 후보 보고서

## 6단계. GitHub 반영

- 민감정보 점검
- 변경사항 커밋
- 추적 가능한 메시지로 기록

산출물:
- 커밋 이력

## 7단계. 주기 운영

- 주간: 최근 3개월 자료 점검
- 월간: 삭제 후보 검토
- 분기: 구조 재평가 및 확장 여부 결정

산출물:
- 운영 점검 로그
